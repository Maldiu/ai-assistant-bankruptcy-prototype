# Dify workflow

Граф приложения «Ассистент юриста» (workflow, advanced-chat):

```
start1 → kb1 (retrieval, top_k=10) → llm1 (GPT-5.6 Sol) → code1 (сборка тикета)
       → if-else1 (code1.has == 1) → http1 (push в датасет «Обращения клиентов»)
                                    → ans1 ({{#code1.reply#}})
```

## Узлы

- `start1` — точка входа.
- `kb1` — retrieval по базе знаний, `top_k=10`.
- `llm1` — LLM-нода с системным промптом из `prompts/system-prompt.md`.
- `code1` — JS-нода, собирает карточку обращения (поля: способ связи, телефон,
  статус клиента, долг, просрочка, доход, имущество, ИП, банкротство в прошлом,
  регион, суть запроса, краткая выжимка переписки). Возвращает `reply` (текст
  клиенту) и `has` (1 если собрано обращение).
- `if-else1` — условие `code1.has = 1`: true → `http1`, false → `ans1`.
- `http1` — POST в датасет «Обращения клиентов».
- `ans1` — ответ клиенту = `{{#code1.reply#}}`.

## Как получить полный DSL

В интерфейсе Dify: приложение → меню «...» → «Export DSL». Сохранить файл как
`workflow/dsl.yaml` в этом репозитории. DSL содержит полный граф, промпт и
код-ноду — он заменяет этот README.

## Файлы в этой папке

- `dify-workflow-draft.json` — полный граф воркфлоу (экспорт через console API), санитизирован.
- `code-node.py` — код-нода (Python): разделение ответа и блока ОБРАЩЕНИЕ.
- `README.md` — описание графа и план по отказоустойчивости.

Системный промпт (правила 1–19) — в `../prompts/system-prompt.md`.
